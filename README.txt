Bizz Fleet Corporation — redesigned website

The redesigned React/Vite website uses the existing Bizz Fleet logo, supplied brand artwork and photographs already used by the original website. Photographs and illustrations describe service areas and do not claim completed projects or client affiliations.

Run locally:
1. Extract bizz-fleet-redesign.zip.
2. Run npm ci.
3. Run npm run dev.

Production build: npm run build
Vercel uses the included vercel.json for direct inner-page navigation.

The enquiry form prepares an email draft addressed to hello.bizzfleet@gmail.com. It does not submit to a server or show a false received confirmation. Visitors review and send the enquiry through their email app; copying and downloading the draft are also available.

Validation: production build, lint of new application code, desktop/mobile visual checks, mobile navigation, service-specific enquiry selection, draft preparation and modal Escape behaviour.
